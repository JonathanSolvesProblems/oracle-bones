# Kotsu, the oracle

Kotsu is the mascot of the Oracle Bones power. Working name, change it if a better one comes.

骨 (kotsu) is "bone" in Japanese, and コツ (kotsu) is "the knack". Ancient Japan had its own
bone oracle, futomani: diviners heated a deer's shoulder blade and read the cracks. Kotsu
does the same thing to dead programs.

## Who Kotsu is

A small spirit that lives in old machines. The power wakes it when it boots a dead binary.
Kotsu asks the program questions, and each answer shows up as a glowing crack in the bone
tablet it carries.

Kotsu never makes up an answer. If the bone did not crack, Kotsu says it does not know. That
is the same rule the oracle law gives the agents, so the mascot and the product say one
thing.

## The look

Three things are fixed. Everything else (gender, hair, outfit, face) is yours to choose.

1. A cracked shoulder-blade tablet, held like a clipboard. The cracks glow.
2. Phosphor green, the colour of an old monochrome monitor, in the eyes and the cracks. It is
   the only accent colour.
3. DOS box-drawing borders (╔═╗ ║ ╚═╝) along the hem of the robe or haori.

Anime style. Chibi proportions (two to three heads tall) for the icon, a fuller pose for the
README header. Spooky and cute for Kiroween, not horror.

## Four poses, each tied to a moment in the product

| Pose | The moment | Used on |
|---|---|---|
| Asking: tablet raised, a DOS boot screen behind | The power boots a dead binary | README header, video title card |
| Reading a crack: leaning in, "3.27" in the crack | The oracle answered | Gallery slide on the first match |
| Refusing: arms crossed in front of a file | The hook blocks an edit to a golden file | Video, at the refusal |
| Asleep on a floppy disk | No target loaded yet | Empty state in the power's README |

## Where Kotsu appears

- Yes: the power's README and icon, the corner of each gallery slide, the video's title and
  chapter cards, the blog post header, the social post image.
- Never: the reviewer's app, its results screen or its printout. A printout goes in a permit
  file, which is a legal record, and the reviewer needs to trust it.
- Never next to anything that reads as FEMA's endorsement.

## What Kotsu must not resemble

- Any existing character. No prompt or brief names an anime, studio, character or artist.
- Kiro's ghost logo. That is the sponsor's mark, and copying it reads as theirs.
- Chinese oracle-bone script used as decoration. It is a real writing system, not a texture.
